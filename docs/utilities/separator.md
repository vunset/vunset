# Separator

A line between items in a menu, a group or a toolbar. Screen readers know
it as a separator.

It's horizontal by default. Inside a [Group](/layout/group) it runs across
the group: upright in a row of buttons, flat in a column.

::: preview menu/Basic
:::

## API Reference

The element carries `data-part="separator"`, `role="separator"`, and its
orientation as `aria-orientation` and `data-orientation`.
