# Addon

Something at one end of a control: an icon, a unit, a count, a clear button.
You can put it in a `FieldGroup`, a `SelectTrigger` or a `ComboboxTrigger`.
Pressing an addon that isn't a button itself still focuses the control.

::: preview field/Addons
:::

## API Reference

The element carries `data-part="addon"`, and `data-side` when you set
`side`.
